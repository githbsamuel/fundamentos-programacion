## Practicas de clase

Carpeta: practicas-clase

#### 1. - AreaRectangulo

- Descripción: Programa que calcula el área de un rectángulo.

#### 2. - CobroLlamada

- Descripción: Programa que calcula el costo de una llamada telefónica según la duración y la tarifa.

#### 3. - CuentaAhorro

- Descripción: Programa que calcula el saldo final de una cuenta de ahorro despues de 12 meses.

#### 4. - MayorEdad

- Descripción: Programa que determina si una persona es mayor de edad según su edad.

#### 5. - NumeroMayor

- Descripción: Programa que determina el número mayor entre tres números ingresados por el usuario.

#### 6. - RestaurantePre

- Descripción: Programa que calcula el total a pagar en un restaurante según el ingreso de personas y aplicacion de tarifas.

#### 7. - SumaNnumeros

- Descripción: Programa que calcula la suma de N números ingresados por el usuario.

#### 8. - VentasProductos

- Descripción: Programa que calcula el total de ventas de productos según la cantidad y el precio.
